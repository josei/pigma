What works in the online editor

The online editor is the full editor, running entirely in your browser. Two features need a Pigma server, and the online copy says so instead of failing:

  • Shared rooms (live collaboration) need a relay server you run yourself.
  • The AI agent (MCP) needs a local or self-hosted endpoint.

Run a server with npm run relay, see the repository's README to get started.
